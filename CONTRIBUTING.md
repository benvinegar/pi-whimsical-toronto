# Contributing

Contributions are welcome.

## Setup

```bash
pnpm install
pnpm check
```

## Phrase guidelines

Working messages should be:

- brief enough for Pi's status area;
- playful rather than hostile;
- related to thinking, coding, debugging, or waiting;
- understandable without claiming to define or authenticate Toronto slang.

Add or update tests when behavior changes. Use Conventional Commit titles, such as `feat: add new working messages` or `fix: clear status after a turn`.
